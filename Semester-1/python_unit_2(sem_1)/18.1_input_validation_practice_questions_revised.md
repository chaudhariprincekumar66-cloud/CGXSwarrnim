# Input Validation — Practice Worksheet

**Topic:** Python Input Validation  
**Level:** Beginner to Intermediate  
**Total Questions:** 25

## Instructions

1. Solve the questions in order. The questions start with basic validation and gradually become more challenging.
2. Use only concepts covered in the input-validation notes: variables, strings, `input()`, `if/else`, loops, `strip()`, string methods, `try/except`, and the `re` module where a regex pattern is provided.
3. **Do not use lists, tuples, dictionaries, or list-based methods.** Questions that are more naturally solved using lists are intentionally not included.
4. For numeric input, handle invalid conversions where needed so the program does not crash.
5. In repeated-input questions, ask again until the user enters valid input.
6. In limited-attempt questions, stop after the stated number of invalid attempts.
7. For regex questions, the required pattern is already provided. Use `re.fullmatch()` to check the complete input.
8. Each question includes sample input/output to help you understand the expected behavior. Your program may display messages with slightly different wording.
